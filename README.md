Projetos para firmar a lógica: variáveis, condicionais, laços e funções.

Esse projeto é capaz de manipular arquivos de texto, criando, modificando eu conteudo, deletando e lendo o que estiver dentro do arquivo

A ideia do sistema é possibilitar ao usuario através do terminal, criar uma lista de tarefas, onde o usuario descreve cada tarefa que deseja salvar e armazenar em um arquivo txt, primeiro fica tudo salvo em memoria, e ao encerrar o sistema
é realizado a criação do arquivo e as tarefas são salvas para serem usadas em outro momento no sistema

Quando o sistema é iniciado ele verifica a existencia de lista de tarefas, se existir ele ja salva ela em memoria para usar no sistema.

O sistema ainda é capaz de remover tarefas tanto da memoria quanto do arquivo txt criado, pode remover de forma individual a tarefa ou remover todas de uma vez

O sistema possibilita também ao usuário, marcar uma tarefa como concluida
